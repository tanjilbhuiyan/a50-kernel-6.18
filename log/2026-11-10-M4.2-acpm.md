# 2026-11-10 M4.2 ACPM IPC for Exynos 9610

## Decision: extend mainline's ACPM driver
Compared drivers/firmware/samsung/exynos-acpm.c (gs101) with 4.14 acpm_ipc.c/acpm_mfd.c and the working M3.6 probe:
- Same: framework header (channels @0x08, count @0x18), the 0x48-byte channel layout, queue handling, sequence number bits 21:16, PMIC commands (TYPE 11:8, REG 7:0; FUNC 7:0, VALUE 15:8, RETURN 31:24).
- Different: initdata base (0x6f00); mailbox doorbell (INTGR0 at 0x08 with channel bit << 16, gs101 INTGR1 at 0x40); no modelled mailbox clock; the gs101 IRQ mask write would hit a status register on 9610, so the mask stays off (the M3.6 probe worked without it).

## Implementation
Kernel branch a50-acpm on a50-usb, commit 11a0a3f45 (reference/m42-acpm/0001-*.patch): mailbox and ACPM data, bindings, DT nodes (mailbox@11900000, SPI 38; apm_sram at 0x2039000; firmware/power-management), config.
