## Test scope

Build static native and compat binaries from the actual r26p0 ioctl
headers and extracted memory/context/sync constants. Assert ioctl numbers
and structure sizes for both ABIs. Each case runs in a child with a fresh
context opened after fork, tracking page and job submission disabled.
No synthetic jobs, shader execution, protected memory or service changes.
Ordinary live UI supplies prior real-GPU job/rendering evidence.

Six cases per ABI:
1. Tracking-page prerequisite, duplicate tracking refusal, descriptor/context cleanup.
2. Cached native allocations (1/2/4/8-page sizes), flags/size/commit query,
   mmap and full data pattern, both cache-sync directions, bounded invalid
   queries/syncs, SAME_VA free semantics and eight unmap/cleanup cycles.
3. Pending-cookie wrong-size mapping refusal, explicit free, double-free refusal.
4. Cached ION heap-0 dma-buf import, query/map, pattern preservation,
   exporter-fd closure before mapping, both sync directions and cleanup.
5. Aligned user-buffer import, reservation/query/cleanup. Noncoherent user
   import is faulted-in but not pinned around external-resource jobs in
   this non-submitting context. Legacy cache sync supports dma-bufs only;
   user-import cache sync must return EINVAL, not a fabricated success.
6. Zero/overcommitted/kernel-only allocations, bad query pointer/address,
   invalid import fd/pointer/type, matched to stock errno behavior.

These are bounded ABI/lifetime/sync-call checks. They do not prove GPU
write/readback coherency on each synthetic buffer or external-resource job
pinning for user imports; no jobs are submitted by the probe contexts.
