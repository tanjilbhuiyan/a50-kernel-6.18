## Limits / open
- Saved stock profiles are bound to `swlan0`; on 6.18 the station is `wlan0`. Test used an in-memory unbind; a real
  install needs a one-time reconnect (new profile on `wlan0`) or a profile migration — not decided.
- MAC is a random local address each boot (no EFS read, writer of `/sys/wifi/mac_addr` on stock still unknown).
- Latency (avg 124 ms, max 313 ms) and throughput (~9 Mbit/s through SSH) look low; likely power save or the
  untuned HIP path; not yet measured against stock.
- Test image includes the NULL test client and H1 diagnostics; clean defconfig/publication not yet refreshed for Wi-Fi.
- Device-node/ABI criterion (moved from M9.2): Wi-Fi exposes `wlan0`/`p2p0`, rfkill `phy0`, nl80211; Android private
  ioctls are rejected by the kernel (no `ndo_siocdevprivate`); not yet exercised explicitly.
