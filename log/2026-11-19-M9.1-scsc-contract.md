## C1 — read-only snapshot (phablet, no root)
`tools`: inline SSH capture; public copy `reference/m91-scsc/c1-stock-snapshot.txt`, hashes
`reference/m91-scsc/vendor-etc-wifi.sha256` (68 files). Found: firmware variant `mx140` in `/vendor/etc/wifi`;
`scsc_wlbt` bound to `119c0000.scsc_wifibt`; netdevs `wlan0`, `swlan0`, `p2p0` on `phy0`; Ubuntu Touch is connected on
`swlan0`; Bluetooth via Android HAL → `/dev/scsc_h4_0` → bluebinder → vhci `hci0` (soft-blocked); `wlbtd` runs in the
container; EFS mounted rw at `/mnt/vendor/efs` by Halium (read only by us); CFG_REQ IRQ count 1.

## C4 — Wi-Fi rfkill block/unblock (owner approved "Yes, toggle Wi-Fi")
`tools/m91/c4_phone_side.sh` (phablet, detached, always unblocks) at uptime 229.7 s: block 232.0, unblock 247.1,
reconnect with DHCP at 257.5 s. CFG_REQ count stayed 1 and the driver logged "Already opened: users=2": the chip does not
reboot, so this records the Wi-Fi **service** start (firmware version string, MIB files, HIP4 sizes, wlbtd write, MAC
from sysfs), not the chip boot. Public redacted extract `reference/m91-scsc/c4-service-restart.txt`
(`tools/m91/redact_c4.py`: SSID, BSSID/MAC, IP addresses removed), state `c4-state.txt`. Wi-Fi back on afterwards.

## Source and config review

sizes and 4.14-only mechanisms (set_fs file access, wake_lock, Exynos pm_qos, exynos_smc, Samsung nl80211 SAE patch).
6.18 has no SCSC code and no wireless options in the A50 defconfig.
