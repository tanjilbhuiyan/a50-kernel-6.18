## Stock facts (reference/stock-dt/dtbo.3.dts ~2168 and __fixups__)
`gpio_keys` (`gpio-keys`): button@2 `KEY_VOLUMEDOWN` (0x72) gpa1-6, button@3 `KEY_VOLUMEUP` (0x73) gpa1-5, button@4
`KEY_POWER` (0x74) gpa1-7 with `gpio-key,wakeup`; gpio flags 0x0f (bit 0 = active low). Pin groups key-voldown/
key-volup/key-power: function 0xf (EINT), no pull, drive 0. The power key is a plain GPIO, not a PMIC key. These match
M4.4's untested guess (`reference/m44-buses/0001-*.patch`).
