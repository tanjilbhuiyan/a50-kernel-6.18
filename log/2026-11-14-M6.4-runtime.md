## Test 4 design and inputs

Source review of LXC's `bpf_program_append_device()` found another policy
gap: a partial access rule matches only if it includes all requested bits.
Therefore `wm` does not cover an `O_RDWR` request. This is a source-derived
finding; the attempted live matrix on test 3 missed its window. Test 4
denies `b *:* rwm`, covering every block open mode and creation. Guest
storage uses host-mounted filesystems, so no raw block reads are required.
Kernel source/features, masks, DT and 420-second timer remain unchanged.
Diagnostics use the correct gralloc service name and include crash logs.

`block_policy_matrix.c` checks character access and RO/WO/RW block opens
plus mknod against an absent SCSI minor, with no block I/O. The new runner
automatically stages the matrix and ION helpers, runs probes, captures
runtime state early and after 220 seconds, then waits for stock restore.
The ION replay runs as guest UID 1000/GID 1003, including both executable
ABIs. These direct ABI checks do not substitute for a real allocator HAL.
