## Startup blockers and mount policy

1. **Confirmed protected write denial.** The [M5.4 dump](../reference/m54-usb-ssh/2026-11-10-netdevices-dump.txt#L540)
   shows the guard rejecting two WRITE(10) requests on EFS (`sda3`) with
   DATA_PROTECT/`0x27`. The superblock write fails, the mount fails and its
   journal aborts. The [stock fstab](../reference/stock-vendor/etc_fstab.exynos9610#L10)
   requests writable EFS and CPEFS. The saved host script looks for a partition
   image first, falls back to the partition label, strips `context` and passes
   the remaining options through. The dump later shows `sdd1` mounted `ro`.
   The exact source and options for that successful mount remain unverified.
2. **Confirmed dependency failure, likely BinderFS exit.** The unit exits 32
   at 21.896 s. `lxc-android-config.service` and `a50-container-prepare.service`
   fail their dependencies, so Android `lxc-start` never runs. The saved
   script handles return codes from individual fstab entries at lines 167–169
   and 208–210 and continues except for its `#endhalium` marker. Under
   `bash -eu`, the later `mount -t binder binder /dev/binderfs -o stats=global`
   at line 256 can terminate the script when the filesystem is missing. This
   fits the config and exit status. The journal excerpt lacks the mount
   command's stderr, so capture the exact command and result in M6.4.
3. **Known runtime layout.** The Android 11 image reports API 30. The packaged
   starter calls `lxc-start -n android -F` with `/init second_stage`. Its
   archived `config` uses `lxc.net.0.type = none`, keeps `net user`, sets an
   unconfined AppArmor profile and `lxc.autodev = 0`, mounts tmpfs `/dev` and
   binds host `/dev/__properties__`, `/dev/socket` and optional `/dev/binderfs`.
   It also mounts proc/sysfs and optionally selinuxfs. The A50 prepare service
   adds a second LXC mount hook through a runtime bind of the config. Verify
   guest device paths and actual udev/LXC exposure at integration. The saved
   pre-start hook edits init rc files if the rootfs is writable. Verify the
   effective rootfs mount and stage any required edits in a runtime layer. The
   Android config has no include of the generic LXC bridge/device templates.
   `VETH`, `BRIDGE` and `OVERLAY_FS` are off in M5.4. The Halium overlay unit
   already succeeded in that boot and the archived image has none of its four
   overlay source directories. Check new mount requirements when observed.
4. **Cgroup compatibility pending runtime evidence.** The tested config has
   PID/IPC/UTS/user/net namespaces, `CGROUPS`, `MEMCG`, `CPUSETS`,
   `CGROUP_FREEZER`, `CGROUP_BPF`, `BPF_SYSCALL`, seccomp and AppArmor. It has
   `MEMCG_V1`, `CPUSETS_V1`, `CGROUP_SCHED`, `CGROUP_PIDS` and `BPF_JIT` off.
   The archived `/system/etc/cgroups.json` defines legacy `blkio`, `cpu`,
   `cpuacct`, `cpuset`, `memory` and `schedtune` paths, and a `Cgroups2`
   hierarchy at `/sys/fs/cgroup` with freezer. Its task profiles reference
   schedtune, cpuset, memory, freezer and CPU uclamp. The stock vendor
   [init rc](../reference/stock-vendor/etc_init_init.exynos9610.rc#L68)
   also references legacy stune/cpuset/freezer. At integration collect
   `/proc/self/mountinfo`, `cgroup.controllers`, `cgroup.subtree_control`,
   effective LXC config and Android init logs. Bring up any needed native
   controllers and adjust runtime profiles based on the observed failures.
5. **Integration policy.** Before enabling normal Android startup, validate
   the effective fstab sources and targets, including any `/userdata/*.img`
   overrides. Skip protected mounts until a consumer needs them. For necessary
   protected ext4 reads, use explicit `ro,noload` to suppress journal replay,
   with no repair and no writable block-device exposure to the guest. Treat
   any rejected or unsafe read-only mount as unavailable. Verify host and
   guest mountinfo and guard logs. If a required service needs writable scratch
   state, prove its path and back it with tmpfs or userdata through a per-boot
   bind or overlay. Keep EFS, SEC_EFS, CPEFS and stock vendor protected.
