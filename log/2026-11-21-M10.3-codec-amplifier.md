# M10.3 — RT5665 codec, TFA9872 amplifier, machine driver (2026-11-21)

## B1 preparation (host only)

Survey (stock DTBO 5, `vogue-rt5665.c`, mainline `rt5665.c`):
- Codec `rt5665@1b` on i2c@13890000 (6.18 `i2c_6`, already enabled on the
  fixed PERI clock, ADR-0007). Supplies O: `regulator_1v8` = S2MPU09 LDO42,
  `regulator_3v3` = LDO40 (both in the 6.18 DT); mapped to mainline AVDD and
  MICVDD. Differential IN1/3/4, DMIC2 data pin 2.
- Stock jack detection uses `jd-src = <2>` (JD1+JD2), a Samsung-only source;
  mainline knows only JD1 and warns on 2. Left out of B1 with the gpa1-2
  interrupt and the SAR button/impedance properties (headset later).
- Clocking: the stock UAIF0 hw_params disables the UAIF0 BCLK Q-channel
  (`set_tristate(0)`) and runs codec PLL1 from BCLK1 to 512 fs; `xclkout`
  (gpq0-1 PMU clock out) is not part of the RT5665 path, so it is left out.
- Mixer controls: the M10.1 check showed mainline covers every codec control
  the HAL paths use except `Disable NG2`. Machine controls the paths use:
  `HEADPHONE`, `HEADSETMIC`, `RECEIVER` pin switches (plus stock's
  `SPEAKER`, `MAINMIC`, `SUBMIC` and `Sound Wakelock`).

Clean `a50-audio` (now 16 commits after M9):
- `1072fa759` card: UAIF0 ops (BCLK kept on while streams use it, PLL1 from
  BCLK1, sysclk 512 fs), stock board widgets, pin switches, `Sound Wakelock`
  on a wakeup source; Kconfig selects `SND_SOC_RT5665`.
- `a0a748616` DT: codec node, UAIF0 pin states (gpb0-1..4, O: aud-i2s0-bus/
  idle), UAIF0 codec link, stock routing.

Test branch `a50-m10-b1-test` a3f5bd537 = A2c b0d0aa421 + those two.
`tools/m10/build_b1.py b1`: config delta vs A2c only `SND_SOC_RT5665` and
`SND_SOC_RL6231`; runtime cpio identical. BOOT `src/m10/boot-b1.img`
0bc9daa42d77be74…, DT `src/m10/dt-b1.img` f73a47e5bb741cfc…; 23 hashes in
`reference/m10-audio/b1-inputs.json`; frozen `src/m10/b1-as-built/`.
Runner `tools/m10/run_b1.sh` (collector `collect_b1.sh`: codec probe,
supplies, DAPM bias, then the A2 card/regression checks; read-only, no PCM).

B1 pass: the RT5665 binds on i2c6 with both supplies on, the card registers
with the codec on UAIF0, and its controls cover the HAL path names as stock
does (except `Disable NG2`); A2c ABOX/card results otherwise unchanged.
