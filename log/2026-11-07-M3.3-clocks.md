# 2026-11-07 M3.3 Exynos 9610 clock driver (CMUs for UFS and USB)

## Provenance (branch a50-clk in src/ack-6.18/common, base a50-dt; patches in reference/m33-clk/)
1. Mainline backports (prerequisite: the 9610 driver uses auto_clock_gate, gate_dbg_offset, option_offset,
   sysreg_clk_regs, which 6.18 lacks). Fetched from GitHub torvalds/linux (`gh api ... application/vnd.github.patch`):
   - 298fac4f4b96 "clk: samsung: Implement automatic clock gating mode for CMUs" (2025-12-22, Peter Griffin; HWACG v7 3/4).
     ADAPTED: 2 clk.c hunks rejected because 6.18 lacks a97fbc3ee3e2 "syscore: Pass context data to callbacks";
     applied by hand to 6.18's samsung_clk_resume(void) / samsung_clk_extended_sleep_init (pass and store sysreg).
   - aafaa4d875fb "clk: samsung: avoid warning message on legacy Exynos (auto clock gating)" (2026-01-09): clean.
   - c9d24fe07902 "clk: samsung: fix sysreg save/restore when PM is enabled for CMU" (2026-01-09): clean.
2. Exynos9610 clock series v3, Alexandru Chimac, 2026-07-22, NOT merged in mainline (checked: no clk-exynos9610.c, no
   exynos9610.dtsi in torvalds/linux master). mbox: https://patchew.org/linux/20260722-exynos9610-clocks-v3-0-c672a2a30889@chimac.ro/mbox
   Message-Ids 20260722-exynos9610-clocks-v3-{1..5}-c672a2a30889@chimac.ro.
   - 1/5 CMU bindings: clean. 2/5 sysreg bindings: context differs (6.18 lacks exynos8895 entries); the same 10
     exynos9610-*-sysreg entries inserted by hand in both lists. 3/5 pll_1061x: last hunk adapted (6.18 tests
     pll->rate_table, mainline pll->rate_count). 4/5 driver (clk-exynos9610.c, 3,715 lines): clean. 5/5 MAINTAINERS: skipped.
   - Driver note (commit text): based on Samsung CAL from https://gitlab.com/Linaro/96boards/e850-96/kernel rev 3c200119457e.
3. DT (our commit 84432e20f): cmu_top 0x12100000, cmu_usb 0x13030000, cmu_fsys 0x13400000 (Samsung 4.14
   cal-if/exynos9610/cmucal-sfr.c:11,16,25, 0x8000 each; TOP/FSYS also match the v1 DT patch and the binding example).
   reg size 0x8000 deliberately: samsung_is_auto_capable() (clk.c:256) enables HWACG only for 0x10000, so all three stay in
   manual gating mode ("incorrect res size for automatic clocks" warning expected). Wiring per the v3 binding.
   UFS clocks in the stock DT (single CAL provider, ids 0x134/0x138) map to CMU_FSYS gates (GOUT_FSYS_UFS_EMBD_*); USB
   (0x28e-0x291) to CMU_USB gates (GOUT_USB_USB30DRD_*).
