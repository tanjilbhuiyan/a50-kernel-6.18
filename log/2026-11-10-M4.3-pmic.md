# 2026-11-10 M4.3 S2MPU09 regulators

## Design
Regulators on a read-only driver (tools/m43/s2mpu09-acpm.c, branch a50-pmic on a50-acpm): is_enabled, get_voltage_sel and list_voltage only, no write call. Table and DT generated by tools/m43/gen_table.py from Samsung's active list (35 entries), stock DT names/flags, baseline min/max. DT binding yaml not written yet; dt-validate not run (tool gone), DT built with W=1.
Baseline table: reference/m43-pmic/baseline-regulators.txt (46 regulators, including non-PMIC ones).
