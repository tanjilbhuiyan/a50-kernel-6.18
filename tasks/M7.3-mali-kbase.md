# M7.3 — Mali kbase r26p0 port
Status: todo · Milestone: M7 · Needs phone: build no / test yes · Depends: M7.1

## Scope

Forward-port the audited kbase r26p0 interface required by the unchanged
vendor libraries. Preserve native/compat ioctl layouts, allocation/import,
cache maintenance, job submission and synchronization. Reuse 6.18-native
facilities where semantics match; do not substitute an incompatible driver
ABI for the fixed userspace contract.

Prove clock/power/address-space prerequisites before GPU jobs. Keep the
six unsupported reserved/secure ION heaps explicit; add support only with
evidenced requirements and correct backing/protection semantics.

## Acceptance criteria
- [ ] Reproducible source/config and expected /dev/mali0 ABI availability.
- [ ] Measured allocation/import/query/sync and job paths pass meaningful checks.
- [ ] Real GPU execution verified with errors/limits recorded.
- [ ] USB/storage/runtime regression checks and clean stock restore/fsck.
