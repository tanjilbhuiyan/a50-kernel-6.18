# M1.2 — Build ACK android17-6.18 GKI for arm64
Status: todo · Milestone: M1 · Needs phone: no · Depends: —

## Why
Establishes the base kernel and its official toolchain (ADR-0001) before any
A50 code is added. Gives the reference Image size for risk R1 (BOOT size).

## Inputs (verified 2026-11-01)
- Source: `https://android.googlesource.com/kernel/common` branch `android17-6.18`
  (HEAD `d9a614feddce`, 2026-10-31; Makefile 6.18.33). Pin the commit used.
- Official build system: Kleaf/Bazel via repo manifest
  `https://android.googlesource.com/kernel/manifest` branch `common-android17-6.18`
  (pulls `build/kernel`, `prebuilts/clang/host/linux-x86`, `prebuilts/rust-toolchain/linux-x86`).
- `gki_defconfig` has `CONFIG_RUST=y`, `CONFIG_ASHMEM=y`, `CONFIG_ANDROID_BINDER_IPC_RUST=m`.

## Steps
1. `repo init -u https://android.googlesource.com/kernel/manifest -b common-android17-6.18 && repo sync -c` into `src/ack-6.18/` (gitignored). Record manifest revision.
2. `tools/bazel run //common:kernel_aarch64_dist` (official GKI build). Record clang + rustc versions from prebuilts.
3. Record: Image size, Image.gz size, build time, disk usage.
4. Also try a plain `make ARCH=arm64 LLVM=1 gki_defconfig Image` with the same prebuilts
   (we will need make-style builds for the A50 tree); note any difference.

## Acceptance criteria
- [ ] GKI `Image` builds; sha256 and size recorded.
- [ ] Toolchain versions (clang, rustc, bindgen) recorded in `reference/ack-build/`.
- [ ] Pinned ACK commit + manifest revision recorded.
- [ ] Image + Image.gz sizes compared with the 57,671,680-byte BOOT budget (note for R1).
- [ ] `log/<date>-M1.2-ack-build.md`; `STATUS.md` updated.
