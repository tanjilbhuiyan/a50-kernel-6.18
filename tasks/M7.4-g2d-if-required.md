# M7.4 — G2D, if required by the graphics contract
Status: dropped (not required for measured single-layer path; reopen conditions below) · Milestone: M7 · Needs phone: if required · Depends: M7.1

## Scope

G2D. If required, port the measured ABI and its clocks/power/SysMMU/fence

record that scoped finding and mark this ticket dropped with evidence;
absence in a short capture alone does not establish general non-use.

- If tested: USB/guard preserved, logs/hashes/source and clean restore saved — no new phone test; saved G2f/G2g/G2h restores retained.

## Decision (2026-11-17)

Drop the G2D implementation for the exercised normal single-layer greeter/display path. Both vendor ABIs tolerate
the failed initialization query and retain the Acrylic object, but explicit G2D task execution still fails without
the device. The tested kernel has no G2D execution backend, while G2g/G2h positively present through Mali/DECON.
This decision is not based only on absence of ioctls in the short baseline captures.
