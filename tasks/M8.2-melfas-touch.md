# M8.2 — Melfas MMS touchscreen
Status: done (2026-11-18; log/2026-11-18-M8.2-touch.md; acceptance 3 moved to M12) · Milestone: M8 · Needs phone: yes · Depends: M8.1

## Scope
Bring up the touch controller described in the stock DT as `melfas,mms_ts` at `reg = <0x48>` on `i2c@13870000`, with
`on_state`/`off_state` pinctrl and a `tsp_ldo_en` supply (`reference/stock-dt/dtbo.3.dts` around line 2215). Samsung's
4.14 driver is `drivers/input/touchscreen/melfas/mss100` (gap matrix: C, small port). 6.18 has `melfas_mip4.c` and
`mms114.c`; whether either speaks this controller's protocol is **unverified** and must be checked against the 4.14
source before choosing port vs mainline. Firmware update paths stay disabled (never write controller firmware).
