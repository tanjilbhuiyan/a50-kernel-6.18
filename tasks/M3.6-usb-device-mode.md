# M3.6 — USB device mode (DRD + PHY + gadget)
Status: todo · Milestone: M3 · Needs phone: yes · Depends: M3.3, M3.4

## Why
A direct link to the laptop. Gap matrix (docs/04-gap-matrix.md:32-34): dwc3-exynos + phy-exynos5-usbdrd need 9610 data; sm5713
(USB-C role/VBUS) is category C.

## Facts / unknowns
- Known baseline issue: the laptop's USB-C port is detected as a PD charger on 4.14, no gadget link (docs/02-baseline.md
  "Known issues" #1). Whether this is the sm5713/PD policy or the cable/port on 6.18 is UNVERIFIED.
- First attempt bypasses sm5713: DT `dr_mode = "peripheral"`, VBUS assumed present.

## Steps
1. 9610 data for dwc3-exynos and the USB DRD PHY; DT nodes.
2. configfs gadget (RNDIS + ACM) from the initramfs.
3. Test with the laptop; if PD detection blocks it, try a USB-A-to-C cable (record which).

## Acceptance criteria
- [ ] The laptop enumerates the gadget (`lsusb`, dmesg on the laptop).
- [ ] RNDIS ping or ACM shell works.
- [ ] `log/<date>-M3.6-usb.md`.
