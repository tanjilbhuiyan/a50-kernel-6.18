# M9.3 — Wi-Fi association and SSH (S4)
Status: todo · Milestone: M9 · Needs phone: yes · Depends: M9.2

## Scope
Bring Wi-Fi through its real Ubuntu Touch userspace path, using the unchanged
vendor firmware and the ported driver. S4 is Wi-Fi association plus SSH over
Wi-Fi (`docs/00-goal.md`).

## Acceptance criteria
- [ ] WLAN interface appears and the expected userspace can discover networks.
- [ ] Owner-selected network associates, receives an address and supports SSH over Wi-Fi.
- [ ] Disconnect/reconnect and normal traffic tested, with packet loss/faults and limits recorded.
- [ ] Input/display/userdata and the recovery USB path remain usable; stock restore/fsck clean.

Do not record passwords or publish SSIDs/MACs; arrange test credentials with the owner when this ticket starts.
