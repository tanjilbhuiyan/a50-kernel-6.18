# M0.3 — USB access despite PD detection
Status: done (log/2026-11-02-M0.3-usb-access.md) · Milestone: M0 · Needs phone: yes · Depends: M0.1

## Why
Laptop USB-C is classified as a PD charger (`power_supply/usb/online=0`), so
usb-moded never enables adb/RNDIS (`docs/02-baseline.md` Known issues). Later
milestones (M3, M5) test USB gadget behaviour and need a reliable PC link.

## Steps
1. Try a USB-A port + USB-A→C cable (if available): check `usb/online`, `adb devices`, RNDIS ssh 10.15.19.82.
2. If no USB-A: apply the runtime override as root:
   `echo "USB_MODED_ARGS=-f" > /run/usb-moded/90-force-pc.conf && systemctl restart usb-moded`
   then verify adb/RNDIS.
3. Record which method is standard; add it to `docs/06-workflow.md`.

## Acceptance criteria
- [x] One documented method gives `adb devices` or ssh over RNDIS from the laptop.
- [x] Method recorded in `docs/06-workflow.md`.
