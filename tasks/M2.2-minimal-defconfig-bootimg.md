# M2.2 — Minimal 6.18 defconfig + boot.img within 57.67 MB
Status: todo · Milestone: M2 · Needs phone: no · Depends: M1.2, M1.4

## Why
First light needs the smallest kernel that can reach pstore + framebuffer,
packed in the format S-Boot accepts.

## Inputs
- Boot header facts (`docs/01-device.md`): `ANDROID!` v1, page 2048, kernel_addr 0x10008000, tags 0x10000100; S-Boot drops header cmdline.
- Compression answer from M1.4.
- a50-halium `build/pack-boot-image.py` / `make-boot-image.sh` as packer reference.

## Steps
1. `a50_firstlight_defconfig`: ARCH_EXYNOS, PSCI, GICv3, arch timer, SIMPLEFB + FB console, PSTORE_RAM, built-in initramfs, `CONFIG_CMDLINE` (no `systempart=`), everything else off.
2. Tiny initramfs: busybox static; prints a banner, writes to `/dev/kmsg`, sleeps, triggers reboot (so pstore holds the log).
3. Pack boot.img (header v1); assert size ≤ 57,671,680.
4. Store artifacts + sha256 in `out/` (gitignored) and the recipe in `tools/`.

## Acceptance criteria
- [ ] defconfig committed; build reproducible (two builds, same sha256).
- [ ] boot.img header verified by a parser (fields equal baseline except sizes).
- [ ] Size budget recorded.
- [ ] `log/<date>-M2.2-firstlight-build.md`.
