# M0.1 — Root SSH key on the phone
Status: todo · Milestone: M0 · Needs phone: yes · Depends: —

## Why
M1.3/M1.5 and all later phone work need root without typing a PIN for each command.

## Inputs
Phone on baseline (`docs/02-baseline.md`), `phablet` key auth working, laptop key `~/.ssh/id_ed25519.pub`.

## Steps
1. Owner, in phone Terminal: `sudo mkdir -p /root/.ssh && sudo cp ~/.ssh/authorized_keys /root/.ssh/ && sudo chmod 700 /root/.ssh && sudo chmod 600 /root/.ssh/authorized_keys`
2. Laptop: `ssh -o BatchMode=yes root@<phone-ip> 'id -u'`

## Acceptance criteria
- [ ] `ssh root@<phone-ip> id -u` prints `0` without a password prompt.
- [ ] Note in `log/` that root key exists (security: devel image, trusted network only).
