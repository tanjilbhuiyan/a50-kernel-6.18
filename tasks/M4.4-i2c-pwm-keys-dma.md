# M4.4 — I2C, PWM, keys, PL330 DMA
Status: in-progress · Milestone: M4 · Needs phone: yes · Depends: M3

## Why
Mainline drivers exist for these (gap matrix category A, `docs/04-gap-matrix.md`). They are DT work, and S2MPB03 (M4.3) needs I2C.

## Facts / unknowns
- Stock DT: `samsung,s3c2440-i2c` and `samsung,exynos5-hsi2c` controllers, `samsung,s3c6400-pwm`, `arm,pl330` (`reference/stock-dt/dt.dtb.0.dts`, from :3548, :5286, :5349).
- Controller clocks must be in the 9610 CMU driver; which CMUs beyond M3.3's are needed is UNVERIFIED.
- Owner: no writes to any device on these buses without a named reason. sm5713 (charger, fuel gauge, MUIC) is left alone here.

## Steps
1. Add DT nodes and clocks; enable one block at a time.
2. I2C: probe only, using `i2cdetect` read mode, and compare addresses with the baseline's `/sys/bus/i2c/devices`.
3. Keys: report events from the volume and power keys.
4. PL330: driver probe and the dmatest self-test only if it is safe to run.

## Acceptance criteria
- [ ] I2C controllers probe; the devices found match the baseline's addresses.
- [ ] Volume and power keys produce input events.
- [ ] PWM and PL330 probe without errors.
- [ ] `log/<date>-M4.4-buses.md`.
